Developer integration

Packages carry a reference recording and delivery settings. Import the package into another browser or integrate it with the Voice Fabric registry. Runtime and model support must be tested on each target platform.

The browser SDK requires HTTP(S), Web Workers and Web Audio; inference uses WebGPU where supported or a compatible fallback. Package transfer does not install the runtime or model.
